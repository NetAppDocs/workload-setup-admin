= Monitor operations with Tracker in NetApp Workload Factory
:icons: font
:imagesdir: ./media/

[.lead]
Tracker in NetApp Workload Factory lets you monitor and track the progress and status of FSx for ONTAP, credentials, and link operations, so you can review task and subtask details and diagnose issues or failures. You can filter and search jobs, download a jobs report, and retry or edit a failed operation directly from Tracker.
