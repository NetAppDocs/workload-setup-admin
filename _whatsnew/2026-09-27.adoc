=== Scheduled tasks in Ask Me

You can now tailor a prompt in Ask Me chat to create scheduled tasks.

Use scheduled tasks to ask Ask Me to run recurring checks and send updates in chat based on the schedule you define.

Example prompts: 

* Check the health and lifecycle status of all FSx for NetApp ONTAP file systems every hour to catch issues early.
* List all accessible AWS FSx file systems every hour to keep an up-to-date inventory.

=== AI agents for Workload Factory

Meet your AI assistant for storage operations. AI agents use your Workload Factory credentials to analyze your environment, helping you find risks, improve workloads, and troubleshoot issues in Workload Factory and Slack.

Access AI agents in the new *Explore Agents* section in Ask Me. By default, agents run in read-only mode and provide recommendations and analysis.

Use *Agents settings* to control how agents work. You can:
- Choose read-only or read-write mode
- Select which credentials agents can use
- Add custom instructions
- Adjust how detailed responses are

Additional controls give you more visibility and control. In read-write mode, agents must get your approval before making changes to AWS, ONTAP, or supported APIs. You can also choose how much detail to see in responses, including information about the agent's reasoning and, in Slack, its tool activity.

Agents also support multi-account environments and easier setup. A single agent can securely work across multiple AWS accounts using multiple credentials. Automatic provisioning simplifies deployment, and custom prompts help tailor agent behavior to your organization's needs.
