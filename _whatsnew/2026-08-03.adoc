=== Custom dashboards

* **Notifications for custom dashboards**

Workload Factory now notifies you when your custom dashboard is ready or if creation fails.

After you create a custom dashboard, you'll get a notification with a direct link to view it. If creation fails, you'll get a notification with a link to try again using your original prompt.

This helps you know when your dashboard is ready and makes it easy to review or recreate it.

link:create-custom-dashboard.html[Learn how to create custom dashboards]

link:configure-notifications.html[Learn about configuring notifications]

* **Private and public custom dashboards**

Custom dashboards now include visibility settings. You can keep a dashboard private or share it with your team.

New dashboards are private by default and visible only to you. You can make a dashboard public at any time to share it with everyone in your Workload Factory account.

Each dashboard card shows a visibility label — Private or Public — so you can quickly see which dashboards are shared.

link:learn-custom-dashboards.html#dashboard-visibility-and-sharing[Learn about dashboard visibility and sharing]

link:manage-custom-dashboards.html#change-dashboard-visibility[Learn how to change dashboard visibility]

=== AI features administration

As a Workload Factory administrator, you can control access to AI features across your organization.

You can:
* Use NetApp-managed AWS Bedrock with Anthropic models (recommended and enabled by default, with monthly credit limits)
* Use your own AWS Bedrock setup with custom configuration
* Turn off all AI features

AI features include Ask Me, custom dashboards, rule builder, CloudShell AI, SAM, and analyzers for EMS, database logs, and latency.

The new administration page lets you manage these settings in one place.

If AI features are turned off, users will see a message that AI is unavailable. Using your own AWS Bedrock configuration requires additional AWS IAM permissions for Bedrock access.
